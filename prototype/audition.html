Quick Haul: type and palette auditions

Phase A, 3 November 2026. Primary reference: Truewerk. Pick one concept from design/concepts.md, one type pairing and one palette below, or write your own.

Every specimen uses the same working headline and placeholder facts (phone in the 555-01xx range, prices as round figures) so the comparison is fair. The Copywriter writes the real lines later.

No hero media exists yet. The only client image is assets/logo.png: a 736 by 1600 phone screenshot of a mockup, with the chrome mark on a slate wall. The mark itself is only 220 by 233 pixels. So "a real frame from the hero media" here means the one real frame we have, the logo mockup, shown at native size. In the specimens the mark is shown 66 px wide, a quarter of its native pixels, so it stays sharp on 2x screens; it cannot go much past 110 px wide until Shawn sends the original file (the 2.6 MB PNG from Fiverr, or a vector).

2. Palettes from the logo's pixels

The logo is close to monochrome: a slate blue wall (hue 219), neutral chrome and a blue-black shadow. There is no colour accent in it to take, so Truewerk's lime cannot come across (V move 6: the palette comes from the logo). Numbered markers on each frame show where every swatch was sampled. Text in the top right of each frame sits on the real wall pixels, and its contrast is measured against the brightest wall pixel in that area. Specimen type in this section is pairing B.
